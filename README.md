## Como executar

### Clone o repositório

git clone https://github.com/RUAN-SANTOS-22/role-radar.git

### Instale as dependências

Dentro da pasta do projeto, execute:

* npm install

### Obtenha as chaves e preencha "src/utils/chaves.js"

Após clonar o repositório, é necessário preencher as duas chaves no arquivo "src/utils/chaves.js".

GEOAPIFY_KEY: para obter essa chave, acesse o site do Geoapify, clique em "GET API KEY", faça seu cadastro e crie um projeto.

* GEOAPIFY_KEY: https://www.geoapify.com/get-started-with-maps-api/

PRIMEUI_LICENSE: para obter essa chave, acesse:

* PRIMEUI_LICENSE: https://primeui.store/primeui

Depois, coloque as duas chaves no arquivo "src/utils/chaves.js".

### Inicie a aplicação

Execute:

* npm run dev

Após iniciar a aplicação, o navegador solicitará permissão para acessar sua localização. É necessário permitir o acesso à localização para que o RolêRadar consiga encontrar e apresentar lugares próximos a você.
